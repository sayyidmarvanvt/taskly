# 🛒 Taskly – Shopping List App (React Native + Expo)

> 📱 My first React Native app built with Expo!

**Taskly** is a simple shopping list app where users can add, delete, and update items. It also includes a countdown timer with haptic feedback and persistent local storage using `AsyncStorage`.

---

## 🚀 Features

- ✅ **Add / Edit / Delete** shopping list items (CRUD)
- ⏱️ **One-minute timer** that updates item background (like overdue)
- 📳 **Haptic feedback** for better UX
- 💾 **Local persistence** using `@react-native-async-storage`
- 🌙 Clean UI built with Expo and React Native components

---


## 📦 Technologies Used

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [AsyncStorage](https://docs.expo.dev/versions/latest/sdk/async-storage/)
- [Expo Haptics](https://docs.expo.dev/versions/latest/sdk/haptics/)
- State management using `useState`, `useEffect`
